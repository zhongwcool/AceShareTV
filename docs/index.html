AceShare

手机、平板和电视上的局域网客户端，用来连接你自己电脑上正在运行的 AceShare。

它做什么

电脑和手机或电视连在同一个 Wi-Fi 后，可以在设备上查看、预览、上传和下载电脑 AceShare 里的文件与文本。数据只在你的局域网里传输，不经过开发者的服务器。

先在电脑上下载并运行服务端

客户端自己找不到内容。需要先在电脑上安装并运行 AceShare 服务端，再打开手机或电视上的应用。

  1. 在电脑上打开 AceShare Releases，下载最新版本。
  2. 在电脑上运行它，并保持窗口开着。
  3. 让手机或电视和这台电脑连接同一个 Wi-Fi。
  4. 打开 AceShare。列表里出现电脑名称后，点进去即可使用。
